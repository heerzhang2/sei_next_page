四、调试常见问题与解决
. 无法启动调试（找不到主类）
原因：VS Code 没有正确识别 Spring Boot 主类（带 @SpringBootApplication 的类）。
解决：
确保主类在 src/main/java 下，且包结构正确。
打开主类文件，VS Code 通常会在方法上方显示 “Run | Debug” 按钮（来自 Language Support for Java）。
或者通过左侧 Run and Debug 面板，点击 “create a launch.json file”，选择 “Java” → “Spring Boot” 模板。
示例 .vscode/launch.json：

Json
编辑
{
  "version": "0.2.0",
  "configurations": [
    {
      "type": "java",
      "name": "Launch SpringBoot App",
      "request": "launch",
      "mainClass": "com.example.demo.DemoApplication",
      "projectName": "demo"
    }
  ]
}
注意：projectName 应与 build.gradle 中的 rootProject.name 一致。

. 热重载（Hot Reload）不生效
VS Code 对 Spring Boot DevTools 的支持不如 IDEA 完善。
解决方案：
确保 build.gradle 中包含：
Groovy
编辑
developmentOnly 'org.springframework.boot:spring-boot-devtools'
启用 VS Code 的 Auto Build（默认开启）。
修改代码后，需手动触发构建（如运行 ./gradlew build -x test）或使用 Gradle Tasks 插件重新编译。
更佳方案：使用 spring-boot:run 任务启动应用（见下文）。
. 使用 Gradle 任务启动调试（推荐方式）
在 VS Code 中按 Ctrl+Shift+P → 输入 “Gradle: Run Task” → 选择 bootRun。
如果需要调试，可在 build.gradle 中配置 bootRun 支持调试参数：
Groovy
编辑
bootRun {
    jvmArgs = ["-agentlib:jdwp=transport=dt_socket,server=y,suspend=n,address=5005"]
}
然后在 VS Code 中创建一个 Remote Attach 调试配置连接到 5005 端口。

问题	原因	解决方案

方案：使用 精确前缀 + path rewrite
外部访问 URL	内部上游	APISIX 路由配置
https://192.168.0.100:9443/frontend/...	http://192.168.0.100:3765/...	uri: /frontend/* → rewrite to /
https://192.168.0.100:9443/admin/...	http://192.168.0.100:3000/...	uri: /admin/* → rewrite to /
🔑 关键：外部路径前缀 ≠ 内部路径，通过 proxy-rewrite 插件剥离前缀
Next.js 示例（next.config.js）最好支持 basePath;    ; module.exports = {
  // 如果部署在 /frontend 下
  assetPrefix: process.env.NEXT_PUBLIC_BASE_PATH || '',
  basePath: process.env.NEXT_PUBLIC_BASE_PATH || '',
}  会导致》路由跳转、它不会修改你代码中显式写的 API 请求路径；
如果你无法修改前端，APISIX 的 proxy-rewrite 已足够（前提是前端用相对路径或根路径 /xxx）。加新应用，只需新增两条路由（前端 + 可选专属 API）
APISIX 的路由规则是 基于完整请求路径匹配的，不是基于“后端内部路径”匹配》"proxy-rewrite": { "regex_uri": ["^/frontend/(.*)", "/$1"] }； 浏览器当前 URL 是：https://gateway:9443/frontend/ 所以 /about 被解析为：https://gateway:9443/frontend/about 同时 proxy-rewrite 把路径重写为：/about
