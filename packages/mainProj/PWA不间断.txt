## 问题1: 为什么 #html 会变成 #rsc？
**根本原因**：Cache API **不支持 URL fragment（#）作为缓存键的区分**！
Cache API 会**忽略 fragment 部分**，把它们当作**同一个键**！所以第二次 `cache.put()` 会覆盖第一次的内容。这就是为什么 `#html` 被 `#rsc` 覆盖的原因。
**解决方案**：使用**查询参数**而不是 fragment 来区分 HTML 和 RS。

## URQL `cache-first`的真实行为；URQL 的 `cache-first` 策略**并不是**"有缓存就不发请求"，而是：
1. **先返回缓存数据**（如果有的话）
2. **然后仍会发送网络请求**来获取最新数据并更新缓存。这实际上是一种 "stale-while-revalidate" 模式。所以你观察到的行为是**正确的、符合预期的**。
对比 `cache-and-network`: 先显示缓存，网络响应后**可能触发重新渲染** 两者都会发网络请求，所以你看到的"效果一样"是正常的。
